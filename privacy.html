隐私政策

生效日期：2026-11-17 · 适用于 iOS 版 Nib

概要

Nib 没有账号、广告、统计分析或跟踪，也不包含第三方 SDK。账目、图片、文字识别、分类与备注建议均在本机处理，不上传给开发者。可选的官方规则及历史汇率下载仅请求下文所述的公开资料，服务提供方可能处理相应的请求元数据。

应用在设备上处理的内容

  • 账目：金额、分类、备注、日期等保存为你设备上的 Markdown 账本文件。
  • 图片：你拍摄、从相册选择、粘贴或通过系统分享送入的截图与小票照片，仅在本机用 Apple 的系统文字识别功能读取金额与文字。原图保存在本机，默认在入账 7 天后自动删除，可在设置中调整；尚未确认的条目不会被删图。
  • 设置：外观、本位币、图片保留天数等偏好保存在本机。

可选的官方规则下载

Nib 默认开启官方规则下载，可在设置中关闭。开启后，检查成功后间隔 72 小时再检查；检查失败后，使用应用时可在一小时后重试。进入前台或打开设置均可触发到期检查，从 GitHub Pages 的固定地址下载版本清单及对应的静态 JSON 规则文件。所有语言共用同一份规则包，不根据界面语言、设备地区或货币选择下载内容。

Nib 不会在请求中附带小票、图片、识别文字、账本、使用记录或由 Nib 添加的用户／设备标识符。GitHub Pages 仍会接收常规网络请求元数据，例如 IP 地址、请求时间、请求路径及标准请求头，适用下方链接的 GitHub 隐私声明。下载的规则只在本机用于分类和备注建议，不改写原始小票备注文字或已有账目。关闭下载、离线或更新校验失败时，应用继续使用已验证的本机规则或内置规则。

可选的历史汇率下载

Nib 默认开启历史汇率下载，可在“设置 → 汇率”中单独关闭，不受官方识别规则开关影响。仅在外币入账需要且本机缓存没有可用汇率时，才从 Frankfurter 的固定公开接口下载以 USD 为基准、限定日期窗口的完整历史汇率表。查看已有账目或以本位币入账不会触发汇率下载。

服务提供方会收到请求的日期窗口，以及 IP 地址、请求时间、请求路径和标准请求头等常规请求元数据。Nib 不发送账目、金额、小票、识别文字、用户所选币种或由 Nib 添加的用户／设备标识符；完整汇率表在本机用于换算和缓存。关闭下载或离线时仍可使用可用的本机缓存，也可为单笔交易手动输入汇率。

交易按交易日期对应的历史汇率折算为入账时的本位币，并同时保留带正负号的原币金额与币种。入账金额固定保存；新下载的汇率不会重估已有账目。更改本位币后，过去已保存的入账币种保留并分别统计。

权限

  • 相机：仅在你选择拍照记账时使用，照片只在本机识别。
  • 照片：通过系统照片选择器读取你主动选中的图片，应用不会访问相册中的其他内容。
  • 剪贴板：仅在你点按粘贴时读取。

你可以随时在系统“设置”中撤销相机权限。

存储位置与 iCloud

账本存放在你选择的位置：iCloud 云盘中的 Nib 文件夹、本机，或你指定的文件夹。如果你选择 iCloud 云盘或其他文件提供方，同步由该服务按你的系统设置完成，并适用其隐私政策；开发者无法访问这些文件。

分享扩展与快捷指令

通过系统分享或快捷指令送入的文字和图片，暂存在本机的应用共享容器中，等待你在应用内确认，不会离开设备。

数据的导出与删除

你可以在应用内导出全部账目。删除账目、删除账本文件或卸载应用即可移除相应数据；存放在 iCloud 云盘或其他文件夹中的账本文件需要你在“文件”App 中自行删除。

儿童隐私

Nib 不面向儿童收集信息。官方规则及历史汇率下载涉及的请求元数据见上文。

本网站

本网站与官方规则静态文件由 GitHub Pages 托管，不含统计脚本或第三方字体。GitHub 可能处理网站访问及规则下载的请求信息（例如 IP 地址），适用 GitHub 隐私声明。
