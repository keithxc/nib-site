支持

遇到问题或有建议，请在 GitHub Issues 提交。Issues 是公开的并需要 GitHub 账号，请不要附上真实账单、付款截图或其他个人信息。

常见问题

  • 账本在哪里？ 在“设置 → 数据位置”查看；账本是每年一个 Markdown 文件，可在“文件”App 中打开。
  • 如何导出？ 在“设置 → 导出与备份”中导出。
  • 如何删除数据？ 见隐私政策中的“数据的导出与删除”。

分类与备注建议

识别、分类与备注建议都在手机本地完成。同一份规则同时支持简体中文、繁体中文、日文、韩文和英文，也适用于旅行中的混合语言小票，不受界面语言、设备地区或货币限制。建议可手动修改；原始小票备注文字和已有账目不会被规则更新改写。

Nib 默认开启官方规则下载，可在设置中关闭。检查成功后间隔 72 小时再检查；检查失败后，使用应用时可在一小时后重试。进入前台或打开设置均可触发到期检查，从固定的 GitHub Pages 地址下载静态规则文件。Nib 不在请求中附带小票、账本或用户／设备标识符；托管服务可能处理 IP 地址等常规请求元数据，详见隐私政策。离线、关闭下载或更新校验失败时，继续使用已验证的本机规则或内置规则。

外币入账与汇率

Nib 会把外币交易按交易日历史汇率折算为入账时的本位币，同时保留带正负号的原币金额与币种。每笔交易只按固定入账金额计入统计，原币金额不会重复计入。休市日可采用交易日之前最近公布的可用汇率，实际汇率日期随记录保存。新汇率不会重估已有账目；更改本位币后，过去的入账币种仍保留并分别显示。

“设置 → 汇率 → 自动下载历史汇率”默认开启，独立于识别规则下载。仅外币入账需要且本机缓存无可用汇率时，才向 Frankfurter 的固定公开接口请求限定日期窗口、以 USD 为基准的完整历史汇率表。服务提供方会收到日期窗口和 IP 地址等常规请求元数据，不会收到你的账目、金额或所选币种。查看已有账目及本位币入账不会请求汇率。关闭下载或离线时可使用可用缓存，也可为单笔交易手动输入汇率。详见隐私政策。
